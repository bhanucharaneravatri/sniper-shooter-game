# UE5 Sniper Shooter Roadmap

## Milestone 1 — Foundation
- Create the Unreal Engine 5 project
- Set up player controller and pawn
- Add basic first-person movement
- Add aiming and scope zoom
- Add simple enemy actor with basic patrol behavior

## Milestone 2 — Combat Loop
- Implement firing logic
- Add ammo and reload state
- Add hit scan or projectile-based hit detection
- Add muzzle flash and impact effects
- Add a basic HUD overlay

## Milestone 3 — Environment
- Build a test range or small battlefield
- Add cover elements and depth cues
- Add lighting pass and atmospheric fog
- Add simple terrain and materials
- Tune the scene for readability

## Milestone 4 — Visual Upgrade
- Improve materials and textures
- Add post-processing and color grading
- Add foliage, decals, and props
- Add dust, smoke, and atmospheric particles
- Improve character and weapon presentation

## Milestone 5 — Replay / Polish
- Add pause menu and game states
- Add multiple enemy waves or a target challenge mode
- Add sound cues and weapon feel tuning
- Optimize project for runtime performance
- Prepare a more polished demo presentation

## Reality check

PUBG-level graphics require a large asset pipeline, world design effort, and optimization work. This roadmap focuses on building a prototype first so that the game becomes playable before the visuals become cinematic.
